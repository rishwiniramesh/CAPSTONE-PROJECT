# 🤖 AI-Based Software Project Management System

## 📌 Project Overview

The AI-Based Software Project Management System is an AI-powered application for analyzing existing software projects.

Users can upload project files such as HTML, CSS, JavaScript, PDF documents, text files, and project images or diagrams. The system analyzes the uploaded project and provides useful project-management insights.

## 🎯 Project Aim

The main aim of this project is to use Artificial Intelligence to understand an existing software project and identify:

- Potential failures and problems
- Project requirements
- Main modules
- Missing or unclear requirements
- Security concerns
- Project risks
- Suggested development tasks
- Recommended improvements
